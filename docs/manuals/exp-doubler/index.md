# Exp-Doubler User Manual

![Exp Doubler](../../assets/ProductThumbnails/Exp-Doubler%20Thumbnail%20976px.jpg)

## Unboxing

Your Exp-Doubler includes:
- 1x Exp-Doubler unit
- 3x 3.5mm male TRS to 6.35mm female TRS adapters (15cm)
- 1x Product Box with printed instructions

## Introduction

The Exp-Doubler can be used with one of two goals in mind:
1. More expression pedals
2. Freeing up a Flexiport without sacrificing the ability to use a second
expression pedal

The Exp-Doubler is used to connect up to 4 expression pedals to two
Flexiports. By providing external 9V DC power through the Exp-Doubler, the
Flexiports on PIRATE MIDI devices are able to read the data from 2 expression
pedals rather than one.

Expression pedals must use a TRS cable.

## Setup

Before plugging anything into the Flexiport, please make sure the Flexiport is
set to the correct mode: “Exp-Doubler In”

Next, plug in the cables between the Flexiports, the Exp-Doubler, and the
expression pedals. You can use 1, 2, 3, or 4 Expression pedals. No need to have all ports connected. 
If needed, use the cable adapters included. 

You can also use any other suitable TRS cable that converts 3.5mm to 6.35mm (¼”).

Lastly, supply power to the Exp-Doubler with a centre-negative 9V DC cable as
found on most guitar pedal power supplies. You will need to supply at least 100mA current through your power supply if using all 4 expression pedals. 

## MIDI Messages

To learn how to assign MIDI messages to the expression pedals, please read
the Expression Messages section of the user manual for the MIDI controller you are
connecting to. The Exp-Doubler is a passive device and doesn't have any software or firmware.
